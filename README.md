# Flask + React Todo List ✅

A simple and user-friendly **Todo List application** built with **React (Vite)** for the frontend and **Flask** for the backend.  
This project was an experiment to integrate a modern frontend with a lightweight backend, focusing on learning, problem-solving, and building a functional product.  

---

## 📖 STAR Breakdown

### ⭐ Situation  
Managing daily tasks is often done with pen and paper or scattered apps. I wanted to build a **full-stack application** where tasks could be added, edited, and managed in real-time using a web interface.  

### 🎯 Task  
The goal was to design a **full-stack Todo List** with:  
- A dynamic **React-based frontend** (bundled using Vite)  
- A **Flask backend** serving the built static files and handling CRUD operations  
- Smooth UI interactions for adding, editing, completing, and deleting tasks  

### ⚡ Action  
- Built the **frontend in React** with components for task input, editing, and completion toggling  
- Used **Vite** for fast bundling and output generation  
- Configured **Flask** to serve the static files and connect them with backend logic  
- Implemented **CRUD operations** in Flask to manage tasks in memory / simple storage  
- Learned the limitations of using Flask to serve React apps (e.g., routing challenges since Flask treats the React build as static files)  

### 🏆 Result  
- Delivered a functional, responsive Todo List app with task management features  
- Gained practical experience in **integrating React with Flask**, understanding trade-offs, and debugging routing issues  
- Learned how to bridge modern frontend workflows with a Python backend, preparing for more complex full-stack projects  

---

## 🚀 Features
- ✅ Add, edit, and delete tasks  
- ✔️ Toggle task completion  
- 🖥️ React components for dynamic rendering  
- ⚡ Fast build process with Vite  
- 🐍 Flask backend serving the app
